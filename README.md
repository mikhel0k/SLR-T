# SLR-T: Система распознавания жестового языка и конвертации в текст

## О проекте

**SLR-T** (Sign Language Recognition - Text) — это система, которая автоматически распознаёт жесты языка жестов и преобразует их в текст в реальном времени с использованием компьютерного зрения и машинного обучения. Проект направлен на улучшение коммуникации для людей с нарушениями слуха, обеспечивая инклюзивность в образовании, здравоохранении и повседневной жизни.

### Основные характеристики

- **Точность распознавания**: 95–97%
- **Задержка обработки**: 0.8–1.0 сек
- **Поддержка**: веб-камера, загружаемые видео
- **Интеграция**: REST API, WebSocket для реального времени
- **Технологии**: STG-GCN (Keras), Mediapipe, FastAPI, JavaScript

## Установка

1. Клонируйте репозиторий:
    
    ```bash
    git clone https://github.com/[ваш-репозиторий]/SLR-T.git
    ```
    
2. Установите зависимости:
    
    ```bash
    pip install -r requirements.txt
    ```
    
3. Настройте окружение:
    
    - Убедитесь, что у вас установлены Python 3.8+, Mediapipe, Keras.
    - Для frontend: Node.js 16+.
4. Запустите сервер:
    
    ```bash
    uvicorn main:app --reload
    ```
    
5. Откройте `index.html` в браузере или запустите frontend:
    
    ```bash
    npm install && npm start
    ```
    

## Использование

1. Откройте веб-приложение.
2. Разрешите доступ к веб-камере.
3. Выполняйте жесты, текст появится в интерфейсе.
4. Для интеграции используйте API (см. `/docs` для Swagger).

## Требования

- **Аппаратное обеспечение**: Стандартный ПК/ноутбук, веб-камера
- **FPS**: ≥30
- **ОС**: Windows/Linux/macOS
- **Безопасность**: HTTPS, TLS 1.2+
